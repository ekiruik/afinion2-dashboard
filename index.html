Data source & setup

This dashboard reads the three ODK forms' submissions straight from Google — no backend, so it can be hosted as a plain static site (e.g. GitHub Pages). Open index.html and edit the CONFIG object near the top of the <script> block:

  • mode: "appscript" (current default) — one Google Apps Script Web App URL returns all three tabs as JSON in a single request. Set appsScriptUrl. See APPS_SCRIPT_SETUP.md for the script code to deploy — the sheet does not need to be publicly shared with this method.
  • mode: "single" — one spreadsheet with three tabs (Referral / Lab Officer / Result Review), read via Google's public gviz endpoint. Set singleSheetId and the three tab names in tabs. Requires the sheet to be shared "Anyone with the link — Viewer".
  • mode: "multi" — three separate spreadsheets, same gviz method. Set the three IDs in multiSheetIds.
